# Consent Photos for Demo

## IMPORTANT: Consent and Safety Notice

All images in this directory are **safe, synthetic test images** created specifically for demonstration purposes. They contain NO real people, NO sensitive content, and NO personal information.

## Images Included

1. **demo_image_1.jpg** - Abstract blue striped pattern (400x300px)
   - Purpose: Primary test image for hash computation demo
   - Content: Geometric pattern with blue and dark stripes
   - Safe for public demonstration

2. **demo_image_2.jpg** - Geometric shapes (400x300px)
   - Purpose: Secondary test image for similarity comparison
   - Content: Circle and rectangle on red background
   - Safe for public demonstration

## Usage in Demos

These images should be used ONLY for:
- Demonstrating the perceptual hashing algorithm
- Testing similarity comparison functionality
- Running automated tests
- Presenting the POC to stakeholders

## What NOT to Use

**NEVER use**:
- Real photos of people
- Images from the internet without explicit consent
- Any potentially sensitive or private content
- Suspected illegal content (immediately report to authorities)

## Consent Statement

These synthetic images were created by the Consent Guardian development team specifically for this proof-of-concept. No consent is required as they contain no real identifiable information.

For real-world use, explicit written consent must be obtained from all individuals in any photo before processing.
